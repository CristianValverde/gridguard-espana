🧠 Layer 5 — Root Orchestrator
🧠 OrchestratorAgent — Root Agent
Manages the main loop · Receives snapshots every 10 min · Queries ML + Markov directly, then calls escalation_planner(P, state) and is instructed to execute its result VERBATIM — the band thresholds and the skill/sub-agent list are no longer written in this prompt, they live in Python (see the escalation_planner card above).
Also consults/records the lessons memory (get_lessons at cycle start, store_lesson at cycle end) — an SQLite-backed record of past decisions, since each monitoring cycle is otherwise a stateless session.

🛟 Reliability Layer — Deterministic Safety Net (runs after the LLM turn)
🛟 escalation_enforcer()
Recomputes escalation_planner's verdict after the Orchestrator's turn from the same known P/state, diffs it against the actual trajectory, and invokes by code (isolated runner, no LLM round-trip through the Orchestrator) any mandatory skill or sub-agent that's still missing. Kept as defense-in-depth independently of Orchestrator model choice — a no-op when the plan was already followed.
5 UNIT TESTS NO PROMPT CHANGE
🛟 _consume_events_safely()
Consumes the Runner's event stream defensively, keeping whatever was already captured instead of losing the whole monitoring cycle when a single Skill turn raises an uncaught pydantic.ValidationError (ADK 2.3.0 does not catch this itself).
4 UNIT TESTS VERIFIED LIVE, NO REGRESSION
