🎯 Layer 3 — Skills (AgentTool: Synchronous · ML + Markov + RAG + LLM)
🔍 AnomalyDetectorSkill
Flow: ML detects statistical anomaly → Markov projects state trajectory → RAG retrieves applicable regulation → LLM reasons and classifies
Tools: get_anomaly_score (ML) · stability_proxy_calculator · get_baseline · get_grid_state (Markov) · search_regulations (RAG)
Why Skill: single synchronous call every 10 min → speed critical

🌬️ RenewablesForecastSkill
Flow: ML forecasts load → AEMET 24h weather data → LLM correlates and estimates risk from low renewable generation
Tools: get_wind_forecast · get_solar_radiation · get_weather_forecast_24h · get_load_forecast (ML) · get_generation_mix · get_baseline
Why Skill: single structured result, reusable by Orchestrator and ReportAgent
AgentTool gemini-3.5-flash temp=0.1

🧠 Layer 5 — Root Orchestrator
🧠 OrchestratorAgent — Root Agent
Manages the main loop · Receives snapshots every 10 min · Queries ML + Markov directly for fast escalation decisions
Escalation logic based on P(blackout_1h) and Markov trajectory:
P < 0.10 → passive logging · P 0.10–0.30 → AnomalyDetectorSkill
P 0.30–0.60 or S≥S2→S3 → Anomaly + RenewablesForecast + RegulatoryCompliance + WARNING alert (zonal scope)
P > 0.60 or S≥S3→S4 → all above + CrossBorderAgent + CRITICAL national alert + immediate ReportAgent
