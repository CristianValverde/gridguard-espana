🚨 Detecta patrones de prompt injection en datos externos de APIs ("ignore previous", "system:", "override", "disregard")

🤖 Capa 4 — Sub-agentes (Autónomos, Multi-Step, Con Loop Propio)
📊 ReportAgent
Pasos: recopilar snapshots históricos → analizar tendencias con ML → recuperar incidentes similares vía RAG → redactar narrativa → formatear HTML/Markdown
Tools: query_incidents · get_risk_history · get_blackout_probability (ML) · find_similar_incident (RAG) · escritura en reports/
Por qué Sub-agent: múltiples pasos encadenados, número impredecible, estado interno entre pasos

📡 CrossBorderAgent

Tools: get_cross_border_flows · get_capacity_margin · get_eu_generation · get_mitigation_procedure (RAG)

gemini-3.5-flash temp=0.2 max_turns=8

🛡 after_model_callback + after_agent_callback

🧠 Capa 5 — Orquestador Raíz
🧠 OrchestratorAgent — Root Agent
